An offline tracker and guide for all 55 official GTA VI trophies: a checklist saved in your browser (with export and import), filters by kind and grade, a spoiler-safe mode that hides story trophies until earned, a three-stage roadmap to the platinum (~200 hours, difficulty 4/10), the one possibly missable trophy called out up front, and a guide for every trophy written in our own words with its sources cited — including the five trophies whose methods are still unconfirmed, marked honestly instead of guessed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:4173/ — the guide runs entirely offline once loaded; no account, no network, no build step.
